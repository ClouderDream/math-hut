## 4. 统一术语表

### 4.1 站点与内容域

| 术语 | 含义 | 备注 |
|---|---|---|
| 文章（Post） | `content/posts/*.md` 的一篇 Markdown 源文件 | 含 front-matter |
| front-matter | 文件头部 `---` 包裹的 YAML 元数据块 | 字段：`title` / `date` / `tags` / `summary` / `slug`(可选) / `draft`(可选) |
| slug | 文章在 URL 中的唯一标识 | 优先取 front-matter 的 `slug`，缺省回退文件名；本项目用英文 |
| 阅读时长 | 由正文字数自动推算的分钟数 | `max(1, ceil(W/350))`，W 剥离代码与 LaTeX 后统计 |
| 标签（Tag） | 文章分类维度，一篇文章可多标签 | 生成 `tags/<标签>/index.html` |
| 草稿（Draft） | `draft: true` 的文章 | 生产构建跳过，且不进搜索索引 / sitemap / RSS |

### 4.2 技术域

| 术语 | 含义 | 备注 |
|---|---|---|
| 静态站点生成器（SSG） | 把 Markdown + 模板编译成纯 HTML 文件的程序 | 本项目为自写 Node 脚本，非 Astro/Hugo |
| 构建期（build-time） | `npm run build` 执行期间 | 公式渲染、代码高亮、搜索索引均在此完成 |
| 运行时（runtime） | 浏览器打开页面时 | 本项目运行时仅有主题切换 / 搜索 / 菜单等约 6KB 自写 JS |
| KaTeX 预渲染 | 构建期把 `$...$` 编译成 HTML+CSS | 读者端不加载 KaTeX JS |
| base path | 站点部署的子路径 | 本项目 `/math-hut/`；换主页仓库时改 `site.config.js` 一处即可 |
| TOC | 由 `##`/`###` 标题自动生成的目录 | 带 slug 锚点 |
| bigram | 中文二元切分，如"微积分" → 微积/积分 | 搜索分词方案，零依赖 |
| 搜索索引 | `dist/search-index.json` | 标题/摘要/标签/正文纯文本，正文截断 1200 字 |

### 4.3 后台与凭证域

| 术语 | 含义 | 备注 |
|---|---|---|
| 后台（Admin） | `dist/admin/index.html` 纯前端管理页 | 无服务端 |
| 管理口令 | 用户自设的一串字符 | 前端 SHA-256 比对，**仅防误操作，非安全边界** |
| PAT | GitHub Fine-grained Personal Access Token | **真正的安全凭证**，授予 Contents: Read and write |
| Contents API | GitHub REST 仓库文件读写接口 | 更新/删除必须带 blob `sha` |
| blob sha | 文件当前内容的 Git 对象哈希 | 缺失或过期会导致 409 Conflict |
| Actions | GitHub CI/CD 流水线 | 后台提交后自动构建部署，约 1.5–3 分钟生效 |
