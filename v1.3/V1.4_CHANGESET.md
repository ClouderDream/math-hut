# v1.4 编辑工作流增强变更集

目标：不改变 v1.3 Editorial 视觉体系，只增强移动端与后台编辑体验。

## 已写入分支的新文件

- `src/assets/css/mobile-nav.css`
  - 1050px 以下首页改为单列
  - 860px 以下提供移动端导航样式
  - 侧栏在平板两列、手机单列
- `src/admin/editor-enhancements.js`
  - Ctrl/Cmd + S 保存并发布
  - Ctrl/Cmd + Shift + S 保存草稿
  - Markdown 编辑区 Ctrl+V 直接粘贴截图并上传
  - 自动生成时间戳图片文件名，避免同名图片静默覆盖
  - 媒体库图片增加“插入正文”按钮
  - 增加 H2/H3/引用/列表/表格快捷按钮
  - 编辑器显示字符数和行数

## 需要接线的现有文件

### 1. `src/templates/partials/head.ejs`

在 `main.css` 与 `code.css` 后增加：

```ejs
<link rel="stylesheet" href="<%= u('assets/css/mobile-nav.css') %>?v=<%= v %>">
```

### 2. `src/templates/partials/nav.ejs`

给导航增加移动菜单按钮：

```ejs
<button class="mobile-menu-btn" type="button" id="menuToggle"
  aria-label="打开菜单" aria-expanded="false" aria-controls="siteNav">☰</button>
```

并把主导航改为：

```ejs
<nav class="nav-links" id="siteNav" role="navigation" aria-label="主导航">
```

在导航末尾增加移动端搜索入口：

```ejs
<a class="mobile-search-link" href="<%= u('search/') %>">搜索</a>
```

现有 `assets/js/menu.js` 会自动接管 `menuToggle` / `siteNav`，无需再写一套菜单 JS。

### 3. `src/generators/admin.js`

生成后台脚本时，把增强脚本拼接到现有 `admin.js` 后：

```js
const adminMain = fs.readFileSync(path.join(root, 'src', 'admin', 'admin.js'), 'utf8');
const enhancementPath = path.join(root, 'src', 'admin', 'editor-enhancements.js');
const enhancement = fs.existsSync(enhancementPath)
  ? fs.readFileSync(enhancementPath, 'utf8')
  : '';
write(`${distAdmin}/admin.js`, adminMain + '\n\n' + enhancement);
```

### 4. `src/admin/github.js`

在 `req()` 的非成功响应处理中增加：

```js
if (res.status === 401 || res.status === 403) clearToken();
```

这样 30 天信任 Token 在失效后会立即从 sessionStorage / localStorage 清理。

## 图片编辑工作流

现有 v1.3 已支持：

1. 点击正文工具栏图片按钮选择文件
2. 图片上传到 `v1.3/content/images/`
3. 自动向正文插入：

```md
![图片说明](images/example.png)
```

4. 把图片直接拖入 Markdown 编辑区，也会自动上传并插入

v1.4 增强后再增加：

5. Ctrl+V 粘贴截图直接上传并插入
6. 媒体库已有图片可点“插入正文”
7. 粘贴图片自动使用时间戳文件名，避免覆盖旧图片

## 关于 SVG

后台只有单人使用时，可以继续保留 SVG 上传。真正重要的是：

- Markdown 渲染保持 `html: false`
- 不允许文章内容直接执行任意 HTML/JS
- PAT 使用 Fine-grained Token，只授权 `math-hut` 仓库的 Contents 读写

因此 v1.4 不强制删除 SVG 上传功能。
